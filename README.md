# Main & Outil

Prototype complet du média de valorisation des artisans d’art.

## Voir le site

Ouvrir `index.html` dans un navigateur ou lancer un serveur statique local.

## Pages

- Accueil, concept et carte du Tour de France
- Annuaire filtrable
- Fiches artisans
- Candidature et contact
- Administration locale de démonstration
- Mentions légales et confidentialité

## Avant la mise en production

- remplacer les photos d’illustration par les photographies définitives ;
- compléter les informations juridiques et choisir l’hébergeur ;
- raccorder les formulaires à une base de données et à un service d’e-mail ;
- sécuriser l’administration avec une authentification ;
- intégrer une solution de consentement avant tout contenu YouTube ou outil statistique.
